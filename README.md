# Curso Básico: Algoritmos y estructuras de datos

Material básico y práctico para entender cómo se organizan, almacenan y manipulan los datos mediante algoritmos.

En [course-units](course-units/) se aborda:

- **Unidad 1: Estructuras lineales:** arreglos unidimensionales, arreglos bidimensionales y matrices.
- **Unidad 2: Estructuras dinámicas:** tipos abstractos de datos y listas enlazadas simples, dobles y circulares.
- **Unidad 3: Pilas y colas:** operaciones, implementaciones estáticas y dinámicas, y colas con prioridad.
- **Unidad 4: Estructuras no lineales:** árboles, árboles binarios, árboles binarios de búsqueda y árboles AVL.

Contenido elaborado para una enseñanza práctica y sencilla.
